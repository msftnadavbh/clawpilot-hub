# Microsoft Pitch Builder

> **Status:** Draft / community-contributed. The skill works as a structured prompt today; production tooling is in progress.

## When to use this skill
Use to draft a customer-tailored Microsoft pitch aligned to current MCAPS  AI, Data, Cloud Migration, Security, Modern Work.narratives 

## What this skill does
1. **Pick the MCAPS  AI Transformation, Data & AI, Migrate & Modernize, Security, Copilot.narrative** 
2. **Tailor to the  industry, current Microsoft footprint, known initiatives.customer** 
3. **Build the  hook, problem framing, Microsoft differentiation, proof points, ROI, next step.pitch** 
4. ** Hebrew + English variants when needed.Localize** 
5. ** slide outline, talk track, executive 1-pager.Output** 

## Inputs to ask the user
- Customer name, industry, size
- Stakeholder role (CIO, CTO, Head of Data, etc.)
- Known initiatives or pains
- Pitch length (5 / 15 / 30 min)

## Output
- Slide outline (title + bullets per slide)
- Talk track per slide
- Executive 1-pager
