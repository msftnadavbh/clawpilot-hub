# LinkedIn Post (MCAPS Voice)

> **Status:** Draft / community-contributed. The skill works as a structured prompt today; production tooling is in progress.

## When to use this skill
Use to draft LinkedIn posts in MCAPS-builder  Hebrew or  for sellers and engineers announcing wins, lessons, or technical insights.English voice 

## What this skill does
1. **Pick the  customer win, lesson learned, technical breakdown, event recap.angle** 
2. **Hook in the first  concrete result or contrarian take.line** 
3. **Story  situation, what we tried, what worked, takeaway.arc** 
4. ** builder, humble, specific (no buzzwords, no humblebrag).Voice** 
5. ** Hebrew with proper RTL or English; preserve product names in English.Localize** 

## Inputs to ask the user
- The actual story / event / result
- Audience (technical peers / customers / leadership)
- Length (short ~80w / medium ~150w / long ~250w)
- Hebrew, English, or both

## Output
- Post draft with hook + story + CTA
- Variant in the other language if requested
- 3 hashtags
