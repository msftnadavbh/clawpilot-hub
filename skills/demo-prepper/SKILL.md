# Demo Prepper

> **Status:** Draft / community-contributed. The skill works as a structured prompt today; production tooling is in progress.

## When to use this skill
Use when prepping a customer-facing  discovery call, architecture walkthrough, or live product demo.demo 

## What this skill does
Builds a complete demo plan you can run from:
1. **Audience  roles, technical depth, known pain points.profile** 
 next step.
3. **Demo  7 beats, each with goal, action, expected result.3script** 
4. **Talk  opening, transitions, closing CTA.track** 
5. **Fallback  what to do if the demo breaks (cached video, screenshot, alternate path).plan** 
6. **Recovery  pre-written one-liners for common failure modes.moves** 

## Inputs to ask the user
- Customer name and industry
- Meeting goal (discovery / pitch / technical deep-dive)
- Time available
- Demo environment status

## Output
- 1-page demo plan (markdown)
- Beat-by-beat script with timing
- Fallback / recovery cheat sheet
